# Magica Backend

API and durable agent runtime for Magica chat. **Postgres** is the source of truth; **Trigger.dev** runs the agent loop and projects Realtime streams to clients.

## What this docs site covers

- Local setup and environment configuration
- Authentication with Clerk
- Application flow, database schema, agent runs, credits, and media
- HTTP API reference for chats, messages, runs, credits, and attachments

## Stack at a glance

| Layer | Role |
| --- | --- |
| `src/app/api/v1` | HTTP: chats, messages, runs, credits, attachments |
| `src/app/api/webhooks` | Magica (Svix) + Transloadit + Clerk |
| `src/services` | Transactions, dispatch, progressive credits, media |
| `src/agent` | Context restore, turn loop, finalize |
| `src/trigger` | `agent-run`, `magica-poll`, reconcile sweeper, Realtime |
