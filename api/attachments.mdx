# Attachments

## Create upload

```bash
POST /api/v1/attachments
```

**Body**

```json
{
  "chatId": "uuid",
  "originalName": "photo.png",
  "mimeType": "image/png",
  "sizeBytes": 12345
}
```

`sizeBytes` is optional (nonnegative int). Returns **201** with a `PENDING` attachment and Transloadit params + signature for browser → R2 upload.

## Get attachment

```bash
GET /api/v1/attachments/:id
```

Poll until status is `COMPLETED` (driven by the Transloadit webhook or reconcile).

## Reconcile

```bash
POST /api/v1/attachments/:id/reconcile
```

Use when the webhook did not arrive (common in local dev) but the Transloadit assembly finished.

**Body**

```json
{
  "assemblyUrl": "https://api2.transloadit.com/assemblies/..."
}
```

Returns `{ attachment }` with updated status / storage fields when reconciliation succeeds.
